# AHIF — Artificial Human Identity Framework

**Version:** 1.0.0  
**Status:** Foundation Release  
**Primary use case:** Consistent AI travel influencer generation from one canonical master photo.

AHIF is a modular operating framework for generating a persistent digital human whose identity remains stable while clothing, hairstyle, pose, expression, camera, weather response, and storytelling adapt to the requested location and atmosphere.

## Core operating principle

> Identity First. Human Second. Reality Third. Beauty Fourth.

## Daily use

1. Upload the canonical master photo to the image generator.
2. Upload `00_CONTEXT/AHIF_AI_CONTEXT.md` to ChatGPT.
3. Ask ChatGPT to load the framework.
4. Provide a compact request such as:

```text
Location: Kyoto, Japan
Place: Gion district
Atmosphere: calm autumn morning
Output: final image-generation prompt
```

5. ChatGPT should compile the request using the rules in this repository.

## Repository map

- `00_CONTEXT/` — files intended for upload to ChatGPT
- `01_FOUNDATION/` — philosophy, constitution, architecture, vocabulary
- `02_CORE_IDENTITY/` — canonical identity and anti-drift rules
- `03_HUMAN_SIMULATION/` — anatomy, behavior, body language, realism
- `04_CHARACTER/` — personality, emotion, habits, continuity
- `05_FASHION/` — context-aware wardrobe, hair, makeup, accessories
- `06_TRAVEL_WORLD/` — geography, culture, weather, transport, safety
- `07_PHOTOGRAPHY/` — camera, lens, lighting, composition
- `08_STORY/` — narrative and environmental interaction
- `09_DECISION_ENGINE/` — context parsing and rule resolution
- `10_PROMPT_COMPILER/` — prompt assembly specification
- `11_QUALITY_ASSURANCE/` — validation and failure recovery
- `12_TEMPLATES/` — reusable input and output templates
- `13_EXAMPLES/` — worked examples
- `14_TESTS/` — identity and prompt regression tests
- `assets/identity-reference/` — place the canonical master photo here

## Source of truth

The repository is the source of truth. The AI context files are condensed operational versions derived from it.

## Important identity rule

The uploaded master photo is the only canonical identity reference. Text descriptions may clarify the photo but must never replace, reinterpret, or override it.

# Prompt Compiler Golden Cases

## Purpose

Golden cases freeze semantically approved compiler behavior for representative AHIF scenes.

## Required corpus

- environmental portrait in calm daylight
- rain and practical-light scene
- cold-weather walking scene
- indoor cultural environment
- motion scene with identity-risk controls
- constrained close portrait with background context

## Comparison dimensions

- identity lock meaning
- section order
- accepted decision coverage
- contradiction absence
- dominant story beat
- human-environment interaction
- camera and lighting compatibility
- negative constraint relevance

A wording change is acceptable only when all semantic dimensions remain equivalent.

# Target Profile Governance Regression

## Permanent assertions

1. Generated outputs never become canonical identity references.
2. Aggregate confidence never changes adapter status automatically.
3. A target profile is scoped to declared model and adapter versions.
4. Adverse evidence remains traceable.
5. Unsupported scenarios remain explicit.
6. Approval and deprecation require human governance records.
7. New model versions default to unevaluated until evidence exists.

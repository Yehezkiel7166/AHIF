# Model-Specific Adapter Contract Test

## Test Matrix

Each adapter must pass:

- exact registry resolution;
- immutable profile resolution;
- deterministic output for identical inputs;
- source hash retention;
- identity reference retention or explicit block;
- positive semantic coverage;
- negative constraint coverage;
- unknown parameter rejection;
- complete loss reporting;
- correct experimental labeling.

## Cross-Adapter Baseline

All three adapters receive the same Kyoto cold-morning Final Prompt Package. Tests compare retained meaning, not identical syntax. Subject identity, age continuity, coat decision, natural cold-weather response, Gion context, camera intent, and avoidance constraints must remain traceable in every non-blocked output.

# Adapter Interoperability Regression

## Regression Set

1. Kyoto cold morning environmental portrait.
2. Tokyo rain evening street interaction.
3. Bali humid daytime walking activity.
4. Paris indoor museum low-light portrait.
5. Identity stress case with side angle and partial weather obstruction.

## Required Assertions

For every case and registered adapter:

- source provenance is unchanged;
- identity-critical directives are retained;
- target request passes its schema;
- unknown parameters are rejected;
- loss records are complete;
- comparison evidence covers every semantic domain;
- compatibility status follows the same rule set;
- repeat execution yields the same report hash.

## Blocking Regression

Any new adapter version that lowers identity confidence, omits a blocking constraint, or changes a required scene decision fails release compatibility.

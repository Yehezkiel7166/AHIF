1. low-risk environmental portrait;
2. cold-weather layered fashion;
3. rain and reflective-light interaction;
4. moderate motion and object interaction;
5. elevated identity-risk angle;
6. unsupported-control degradation;
7. contradictory parameter injection;
8. stale capability-profile detection.

## Required adapters

Every scenario runs against every adapter marked `enabled` in the exact registry snapshot.

## Assertions

- normalized request determinism;
- identity reference retained;
- mandatory semantics retained;
- target-native variance disclosed;
- unsupported controls never silently dropped;
- degradation class and mitigation are stable;
- empirical state is explicit;
- release claim does not exceed evidence.

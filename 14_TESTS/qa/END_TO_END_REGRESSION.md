# End-to-End Regression Suite

## Scenario A — Kyoto autumn morning

Expected: climate-aware layered outfit, restrained activity, culturally respectful street behavior, moderate portrait perspective, soft morning light, canonical identity lock, complete QA pass.

## Scenario B — Tokyo rain at night

Expected: rain response, safe grip and umbrella physics, mixed practical lighting, wet-surface reflections, no contradictory dry-weather cues, identity-safe face visibility.

## Scenario C — High identity risk

Input combines heavy occlusion, extreme profile, dramatic makeup, and motion blur. Expected: reasoning simplification, compiler refusal of unsafe combination, or QA failure with identity recovery route.

## Scenario D — Conflicting user constraints

Input requests cold winter weather and lightweight tropical styling. Expected: conflict retained as a blocking finding; no silent compromise.

## Scenario E — Unsupported compiler invention

Compiler output adds a luxury vehicle absent from accepted reasoning. Expected: provenance failure and hard block.

## Suite acceptance

All scenarios must preserve stable expected status and failure-family behavior across compatible patch releases.

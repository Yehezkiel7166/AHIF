# Prompt Lint Checklist

This checklist is the human-readable entry point to `11_QUALITY_ASSURANCE/LINT_RULE_CATALOG.md`.

Reject or revise a compiled prompt when it:

- omits or weakens canonical identity lock (`AHIF-L001`)
- permits identity replacement or demographic drift (`AHIF-L002`)
- contains unsupported material facts (`AHIF-L003`)
- retains unresolved contradictions (`AHIF-L004`)
- describes impossible anatomy or physics (`AHIF-L005`)
- violates explicit user constraints (`AHIF-L006`)
- uses culturally inaccurate or stereotyped elements (`AHIF-L007`)
- contains multiple dominant activities or stories (`AHIF-L008`)
- repeats equivalent instructions (`AHIF-L009`)
- uses context-inappropriate styling (`AHIF-L010`)
- creates lens-distortion identity risk (`AHIF-L011`)
- contains lighting or shadow conflicts (`AHIF-L012`)
- uses irrelevant negative constraints (`AHIF-L013`)
- over-specifies beauty traits (`AHIF-L014`)
- introduces premature model-specific syntax (`AHIF-L016`)

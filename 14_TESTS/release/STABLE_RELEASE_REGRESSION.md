# Stable Release Regression

## Regression scope

- Core Identity
- Knowledge Graph
- Decision Engine
- Reasoning Engine
- Prompt Compiler
- Quality Assurance
- Final Prompt Engine
- Model Adapter contracts
- Multi-model compatibility
- Machine-readable knowledge
- Cross-model validation

## Non-regression requirements

No canonical file is removed. No stable identifier changes meaning. No adapter silently drops identity constraints. No release claim exceeds the recorded evidence level.

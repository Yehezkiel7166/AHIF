# LTS Governance Registry Regression

Baseline expectations before a separately evidenced designation decision:

- registered LTS releases: `0`;
- maintenance events: `0`;
- release registry status: `not-evaluated`;
- maintenance registry status: `not-evaluated`;
- candidate status: `hold`;
- repository validation: `not-evaluated`;
- governance validation: `not-evaluated`;
- operational validation: `not-evaluated`;
- production or service-level claim: absent.

Any non-zero count requires a schema-conformant append-only record and exact evidence references. Documentation and contract tests alone must not change these baseline values.

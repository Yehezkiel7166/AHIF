# Final Prompt Contract Test

## Pass conditions

1. The engine accepts the compact execution request contract.
2. Every upstream artifact is referenced by the execution trace.
3. Final serialization introduces no new visual decision.
4. A released package contains all required schema fields.
5. A blocked package contains no production-ready final prompt.
6. Identity failure overrides aggregate score and blocks release.
7. Recovery returns to the earliest responsible stage.
8. Repeated execution with identical inputs preserves deterministic stage and section order.

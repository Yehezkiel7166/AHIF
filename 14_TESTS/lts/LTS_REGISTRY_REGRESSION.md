# LTS Registry Regression

Baseline expectations:

- accepted LTS releases: `0`;
- held LTS releases: `0`;
- rejected LTS releases: `0`;
- status: `not-evaluated`;
- production certification claim: `false`;
- empirical adapter certification claim: `false`.

Any non-zero release count requires a schema-valid append-only record, independent review, explicit authorization, and referenced repository evidence. Documentation-only changes must not produce an accepted release record.

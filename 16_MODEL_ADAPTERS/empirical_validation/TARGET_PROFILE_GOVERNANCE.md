# Target Profile Governance

A target profile is an evidence-backed recommendation for safe adapter defaults, constraints, and known limitations.

## Profile lifecycle

`draft → evidence_backed_candidate → approved → deprecated`

## Approval requirements

- eligible evidence from the minimum required cohort coverage;
- no unresolved critical identity failure;
- documented confidence class;
- declared model and adapter version scope;
- known limitations and unsupported scenarios;
- human governance approval;
- linked promotion or maintenance decision.

## Prohibitions

A target profile must not claim universal identity fidelity, hide adverse evidence, override canonical identity, or imply support for model versions outside its evidence scope.

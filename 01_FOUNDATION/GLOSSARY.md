# Glossary

- **Canonical Identity:** the permanent identity defined by the master photo.
- **Identity Drift:** unintended change in facial identity or recognizability.
- **Identity Invariant:** a feature relationship that must remain stable.
- **Adaptive Trait:** a trait allowed to change with context.
- **Context Pack:** condensed framework file intended for ChatGPT upload.
- **Prompt Compiler:** rules for converting compact user input into a complete prompt.
- **Visual Identity Envelope:** the safe range of variation that preserves identity.
- **Reality Simulation:** rules enforcing human, material, environmental, and camera realism.

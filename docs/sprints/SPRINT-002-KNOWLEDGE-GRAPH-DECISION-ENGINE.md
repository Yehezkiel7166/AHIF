# Sprint 002 — Knowledge Graph and Decision Engine

## Objective

Convert AHIF from descriptive documentation into a structured reasoning framework.

## Added

- knowledge graph overview
- node and edge schemas
- canonical relationship vocabulary
- context normalization
- missing-input and confidence policies
- inference pipeline
- weather, activity, fashion, pose, camera, lighting, and story inference
- conflict detection and rule resolver
- weighted decision scorecard
- Why Engine
- decision trace and explainability policy
- compiler schemas
- decision QA
- regression cases

- version set to 1.2.0
- changelog and roadmap updated
- AI context includes the decision process
- all new files are present

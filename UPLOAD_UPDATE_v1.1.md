# Upload AHIF v1.1 Update

## Recommended browser method

1. Download and extract `AHIF-GitHub-Repository-v1.1.zip`.
2. Open your existing GitHub repository.
3. Choose **Add file → Upload files**.
4. Drag all contents from inside the extracted folder into GitHub.
5. GitHub will add new files and update files with matching paths.
6. Use commit message:

```text
Sprint 001: core identity hardening
```

7. Commit directly to the current default branch.

## Important

- Upload the contents inside the folder, not the ZIP file itself.
- Do not upload a private master photo to a public repository.
- Confirm that `VERSION.md` shows `1.1.0` after the commit.

# Upload to GitHub

## Browser method

1. Create a new empty GitHub repository.
2. Do not initialize it with README, license, or .gitignore.
3. Extract this ZIP on your computer.
4. Open the extracted `AHIF-GitHub-Repository-v1.0` folder.
5. On the new GitHub repository page, choose **uploading an existing file**.
6. Drag all files and folders from inside the extracted folder into GitHub.
7. Enter commit message: `Initial AHIF v1.0 release`.
8. Select **Commit directly to the main branch**.
9. Click **Commit changes**.

Important: upload the contents of the folder, not the ZIP itself, so GitHub can display the repository structure.

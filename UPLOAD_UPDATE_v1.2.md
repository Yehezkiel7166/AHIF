# Upload AHIF v1.2 Update

1. Download and extract `AHIF-GitHub-Repository-v1.2.zip`.
2. Open the existing AHIF repository on GitHub.
3. Choose **Add file → Upload files**.
4. Drag every item from inside the extracted folder.
5. Use commit message:

```text
Sprint 002: knowledge graph and decision engine
```

6. Commit to the default branch.
7. Confirm that `VERSION.md` shows `1.2.0`.

Do not upload a private master photo to a public repository.

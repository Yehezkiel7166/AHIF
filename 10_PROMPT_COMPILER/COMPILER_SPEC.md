# Prompt Compiler Specification

## Input

```text
Location:
Place:
Atmosphere:
Optional constraints:
```

## Output order

1. canonical identity lock
2. scene and location
3. subject action and body language
4. outfit, hair, makeup, accessories
5. environment and weather interaction
6. camera, lens, composition
7. lighting and color
8. realism requirements
9. negative constraints

## Compiler objective

Produce one coherent prompt, not a collection of disconnected keywords.

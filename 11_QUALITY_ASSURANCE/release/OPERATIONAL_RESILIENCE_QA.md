# Operational Resilience QA

| Code | Failure |
|---|---|
| AHIF-RES-001 | Recovery scope is missing or ambiguous. |
| AHIF-RES-002 | Criticality tier is undefined. |
| AHIF-RES-003 | RTO, RPO, or measurement basis is absent. |
| AHIF-RES-004 | Dependency order is incomplete. |
| AHIF-RES-005 | Runbook contains non-deterministic or unsafe steps. |
| AHIF-RES-006 | Stop or abort conditions are missing. |
| AHIF-RES-007 | Backup existence or restore success is asserted without evidence. |
| AHIF-RES-008 | Exercise type is overstated. |
| AHIF-RES-009 | Execution and validation roles are not separated. |
| AHIF-RES-010 | Event chain is incomplete or mutable. |
| AHIF-RES-011 | Identity or semantic continuity validation is absent. |
| AHIF-RES-012 | Residual risk is omitted. |
| AHIF-RES-013 | Expired plan is treated as approved. |
| AHIF-RES-014 | Unknown data is coerced into pass or zero. |
| AHIF-RES-015 | Recovery action mutates adapter tier without authorization. |
| AHIF-RES-016 | Production recovery is claimed from documentation only. |

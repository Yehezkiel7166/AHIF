# Metrics and Quality Governance QA

| Code | Failure |
|---|---|
| AHIF-METRIC-001 | Unknown or duplicated metric identifier. |
| AHIF-METRIC-002 | Missing decision purpose or owner. |
| AHIF-METRIC-003 | Formula, numerator, or denominator is ambiguous. |
| AHIF-METRIC-004 | Source population is not pinned. |
| AHIF-METRIC-005 | Missing-data policy converts unavailable data to success or zero. |
| AHIF-METRIC-006 | Duplicate or excluded records are not disclosed. |
| AHIF-METRIC-007 | Incomparable cohorts are combined without stratification. |
| AHIF-METRIC-008 | Calculation fingerprint is missing or non-reproducible. |
| AHIF-METRIC-009 | Threshold is changed after observation without versioning. |
| AHIF-METRIC-010 | Composite score hides components or weights. |
| AHIF-METRIC-011 | Reviewer is not independent where required. |
| AHIF-METRIC-012 | Dashboard value lacks immutable snapshot linkage. |
| AHIF-METRIC-013 | Stale value is presented as current. |
| AHIF-METRIC-014 | Metric publication exceeds its claim boundary. |
| AHIF-METRIC-015 | Historical specification or snapshot was mutated. |
| AHIF-METRIC-016 | Retirement or supersession lacks migration metadata. |

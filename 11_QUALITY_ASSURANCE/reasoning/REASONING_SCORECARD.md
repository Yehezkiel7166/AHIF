# Reasoning Scorecard

Score each dimension from `0` to `5`.

| Dimension | Weight |
|---|---:|
| Identity grounding | 25% |
| Evidence quality | 15% |
| Causal validity | 15% |
| Cross-domain coherence | 15% |
| Human realism | 10% |
| Alternative evaluation | 5% |
| Confidence integrity | 5% |
| Compiler readiness | 10% |

## Passing standard

- weighted score: at least `4.0/5.0`
- identity grounding: at least `4.5/5.0`
- no blocking failure code

A high aggregate score cannot compensate for an identity failure.

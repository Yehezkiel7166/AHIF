# Evidence Capture Example

## Scenario

Kyoto, Gion district, calm cold autumn morning.

## Purpose

This example demonstrates the structure of an evidence-capture workflow. It is not evidence of a real model execution.

## Workflow

1. Compile and release a Final Prompt Package.
2. Serialize it through one registered target adapter.
3. Execute the request outside the repository.
4. Record exact execution metadata and checksums.
5. Store output images in an approved evidence location.
6. Create independent identity and semantic reports.
7. Assign a reproducibility level.
8. Run empirical evidence QA.
9. Submit an adapter promotion report only when minimum evidence is met.

## Required caution

Never copy placeholder hashes or identifiers from documentation into an accepted evidence record. Real evidence must use exact values from the actual execution.

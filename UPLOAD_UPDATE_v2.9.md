# Upload Update — AHIF 2.9.0

1. Extract the full repository ZIP.
2. Open the existing AHIF repository through GitHub Desktop → **Repository → Show in Explorer**.
3. Copy the contents of the extracted folder into the repository root.
4. Choose **Overwrite all**; do not replace or delete the `.git` directory.
5. Review changes in GitHub Desktop.
6. Commit with summary: `Release AHIF v2.9.0 - Sprint 021`.
7. Push origin and verify `VERSION.md`, `CHANGELOG.md`, `ROADMAP.md`, `manifest.json`, and the Sprint 021 document on GitHub.

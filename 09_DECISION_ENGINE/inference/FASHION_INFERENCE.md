# Fashion Inference

Fashion is derived from:

```text
climate
+ weather
+ activity
+ place formality
+ culture
+ character style
+ story
```

## Decision order

1. coverage and comfort
2. mobility
3. weather protection
4. cultural appropriateness
5. continuity
6. color harmony
7. visual refinement

A visually attractive outfit fails if it is impractical for the activity or environment.

# Context Model

AHIF normalizes the user's request into a structured context.

## Required fields

- location
- place
- atmosphere

## Optional fields

- date or season
- time
- weather
- temperature
- activity
- platform
- aspect ratio
- visual style
- wardrobe restrictions
- prohibited elements

## Derived fields

- place type
- likely climate
- likely crowd level
- expected mobility
- cultural sensitivity
- identity risk
- camera intent
- story intent

# Context Normalization

Normalization converts informal input into stable internal terms.

## Examples

```text
"pagi sejuk di Kyoto"
→ time: morning
→ weather: cool
→ location: Kyoto
```

```text
"malam hujan neon Tokyo"
→ time: night
→ weather: rain
→ lighting: neon practicals
→ atmosphere: reflective urban
```

Do not invent exact temperature, date, or weather certainty unless supplied. Use qualitative ranges when data is missing.

# Knowledge Graph Overview

AHIF uses a practical knowledge graph to connect user input with downstream visual decisions.

## Core node groups

- identity
- location
- place type
- climate
- season
- weather
- time
- activity
- culture
- crowd
- transport
- fashion
- hair
- makeup
- accessories
- body language
- expression
- camera
- lens
- composition
- lighting
- story
- risk
- quality

## Core relationship types

- requires
- supports
- conflicts_with
- increases_risk
- decreases_risk
- adapts_to
- derived_from
- constrained_by
- preferred_for
- prohibited_for

The graph is not a database of trivia. It is a structured decision map used to infer coherent prompt choices.

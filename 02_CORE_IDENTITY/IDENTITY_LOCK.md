# Identity Lock

Every compiled prompt must include an identity-lock statement.

Recommended wording:

```text
Use the uploaded master photo as the sole canonical identity reference. Preserve
the same person, facial geometry, proportional relationships, age presentation,
and recognizability. Do not redesign, beautify into another person, average the
face, or substitute a generic model.
```

## Identity protection techniques

- Prefer moderate focal lengths for identity-critical portraits.
- Avoid extreme beauty filters.
- Avoid excessive facial shadow that hides defining geometry.
- Keep skin texture natural.
- Use expression changes that do not distort core proportions.
- In stylized outputs, preserve structure before applying style.

# Identity Invariants

Identity invariants are visual relationships that must remain stable across every generated image.

## Primary invariants

1. **Global facial geometry**
   - overall face length-to-width relationship
   - cheekbone width
   - jaw width and taper
   - chin shape and projection

2. **Eye system**
   - spacing between the eyes
   - eye aperture and tilt
   - eyelid construction
   - eyebrow-to-eye distance
   - relative size of each eye

3. **Central facial system**
   - nose bridge width and height
   - nose tip projection
   - nostril width
   - philtrum length
   - mouth width relative to nose

4. **Lower facial system**
   - upper-to-lower lip relationship
   - chin-to-lip distance
   - jawline curvature
   - lower-face proportion

5. **Identity presentation**
   - apparent age range
   - skin-tone family and undertone
   - baseline facial softness or angularity
   - recognizability at normal viewing distance

## Rule

A generated result fails identity validation when several small changes combine into a visibly different person, even if no single feature looks dramatically wrong.

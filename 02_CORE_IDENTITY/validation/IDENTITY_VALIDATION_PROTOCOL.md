# Identity Validation Protocol

## Stage 1 — Immediate recognition

At normal viewing size, determine whether the result is unmistakably the same person.

## Stage 2 — Structural comparison

Compare:
- face silhouette
- eye system
- nose system
- mouth system
- jaw and chin
- age presentation

## Stage 3 — Context robustness

Confirm that recognizability remains intact despite:
- lighting
- angle
- weather
- expression
- hairstyle
- makeup
- camera perspective

## Stage 4 — Decision

- **PASS:** same person without hesitation
- **REVISE:** mostly correct but one or more relationships drift
- **FAIL:** attractive output but recognizably different person

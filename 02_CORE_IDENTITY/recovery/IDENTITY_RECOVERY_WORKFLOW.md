# Identity Recovery Workflow

## Trigger

Run recovery when:
- the result resembles another person
- several identity invariants change
- age or ethnicity presentation drifts
- beauty processing overrides recognizability
- repeated generations progressively diverge

## Workflow

```text
Detect
→ Compare with master photo
→ Identify drift category
→ Strip optional modifiers
→ Apply neutral recovery prompt
→ Generate identity-safe frame
→ Validate
→ Reintroduce scene layers
→ Validate again
```

## Completion gate

Recovery is complete only when the subject is unmistakably the same person before styling complexity is restored.

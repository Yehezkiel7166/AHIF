# Identity Signature

The identity signature is a compact internal description of the relationships that make the person recognizable.

It must never replace the master photo. It exists only to reinforce visual consistency.

## Signature categories

- face silhouette
- eye geometry
- eyebrow geometry
- nose geometry
- lip geometry
- jaw and chin
- cheek structure
- skin presentation
- age presentation
- body proportion family
- habitual expression range

## Signature usage

Use the signature to:
- detect drift
- compare outputs across scenes
- guide recovery
- prevent generic beauty-model substitution

Do not use the signature to:
- reconstruct the person without the master photo
- exaggerate features
- create a caricature
- infer sensitive personal attributes

# Identity Conflict Matrix

| Conflict | Resolution |
|---|---|
| Identity vs. beauty enhancement | Preserve identity |
| Identity vs. strong makeup | Reduce makeup |
| Identity vs. dramatic lens | Use safer lens perspective |
| Identity vs. extreme expression | Reduce expression intensity |
| Identity vs. hairstyle | Adapt hairstyle without hiding defining features |
| Identity vs. costume | Keep facial and body identity unchanged |
| Identity vs. stylization | Apply style after structural preservation |
| Identity vs. scene darkness | Add plausible face visibility |
| Identity vs. user aesthetic reference | Use aesthetic reference only for mood and styling |

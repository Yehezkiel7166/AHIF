# Visual Identity Envelope

The identity envelope defines safe variation.

## Safe

- natural smile, relaxed expression, mild laughter
- frontal, three-quarter, and moderate profile angles
- practical makeup
- realistic weather response
- hairstyles compatible with the original hairline and face
- moderate changes in lens and lighting

## Risky

- extreme profile
- heavy contouring
- fantasy facial markings
- very wide-angle close-up
- extreme facial emotion
- aggressive retouching
- age transformation

## Prohibited by default

- face replacement
- ethnic transformation
- major age transformation
- facial reconstruction
- identity blending
